# Chrysalide-front

Frontend du projet Chrysalide regroupant les applications React + Vite.

## 📁 Architecture Frontend

- **`client/`** : Espace Client React (Vite) — Port 5173
- **`superadmin/`** : Tableau de bord SuperAdmin React (Vite) — Port 5174

## 🚀 Démarrage Rapide

### Client Frontend
```bash
cd client
npm install
npm run dev
```

### SuperAdmin Dashboard
```bash
cd superadmin
npm install
npm run dev
```
